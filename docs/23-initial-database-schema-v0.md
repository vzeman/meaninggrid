# Initial Database Schema V0

## Purpose

This document turns the flexible data model into a first implementation schema.

The v0 schema should support:

- local Site Audit workflow
- future modules without schema rewrites
- reprocessing
- evidence and auditability
- embeddings and vector store adapters
- basic MCP/context packs

It should not try to model every future enterprise feature.

## Conventions

Database:

```text
Postgres 16+
pgvector extension enabled
```

ID strategy:

```text
uuid primary keys generated by application or database
```

Timestamp strategy:

```text
timestamptz
created_at not null default now()
updated_at nullable or maintained by application
```

JSON strategy:

```text
jsonb for properties_json, labels_json, classification_json, config_json,
artifact_json, metadata_json
```

Status fields:

Use `text` with application-level constants first. Add database enum/check
constraints later when states are stable.

Naming:

```text
snake_case tables
snake_case columns
singular foreign key prefixes: dataset_id, entity_id
plural table names
```

## Required Extensions

```sql
create extension if not exists pgcrypto;
create extension if not exists vector;
```

## Initial Indexes

Core scoping:

```sql
create index on datasets (tenant_id, workspace_id);
create index on sources (dataset_id);
create index on raw_objects (dataset_id, source_id);
create index on source_events (dataset_id, source_id, received_at);
create index on entities (dataset_id, entity_type_id);
create index on entities (dataset_id, canonical_uri);
create index on content_units (dataset_id, entity_id);
create index on content_chunks (dataset_id, entity_id);
create index on metric_values (dataset_id, entity_id, observed_at);
create index on analysis_runs (dataset_id, created_at);
create index on insights (dataset_id, insight_type, severity);
create index on jobs (tenant_id, status, scheduled_at);
```

JSONB:

```sql
create index entities_labels_gin on entities using gin (labels_json);
create index entities_properties_gin on entities using gin (properties_json);
create index metric_values_dimensions_gin on metric_values using gin (dimensions_json);
create index content_chunks_labels_gin on content_chunks using gin (labels_json);
```

Add JSONB indexes only when queries use them.

## Seed Requirements

Seed must create:

- tenant: `local`
- user: `admin@local.meaninggrid`
- workspace: `Default Workspace`
- module: `site_audit`
- module installation for default workspace
- entity types for Site Audit
- relation definitions for Site Audit
- metric definitions for Site Audit
- embedding model record for default local model

Seed must be idempotent.

## Future Tables Not In V0

Do not implement these until needed:

- event_routes
- context_units
- agent_subscriptions
- context_notifications
- shared_memory_items
- module_entitlements
- access_policies
- OIDC tables
- billing tables
- ClickHouse replication metadata
- streaming consumer groups
- graph database sync tables

The v0 schema should leave room for them through IDs, JSONB metadata, and
module resource registration.
